## Reproduction

From `/home/ubuntu/timestransfer`:

```sh
MPLCONFIGDIR=/tmp/thesis-mpl .venv/bin/python scripts/build_thesis_artifacts.py
MPLCONFIGDIR=/tmp/thesis-mpl .venv/bin/python scripts/verify_thesis_package.py
```

The generator reads the historical `outputs/`, `outputs/timesfm_tuning/`, `outputs/analysis/`, cached `data/`, current configuration and implementation. It writes only the new package. `--package /path/to/fresh-directory` produces the same generated assets in another directory; authored thesis prose is maintained in this package, not generated by that command. `artifact_manifest.json` lists inputs, SHA-256 hashes, output paths and transformations. Static settings/literature/variable tables are traced in `ledger.md`; numeric score tables are generated from CSVs. `delivery_manifest.json` records final package hashes.

From `/home/ubuntu/thesis`, the existing XeLaTeX/Biber toolchain is used:

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build/experiments main.tex
```

Required environment packages installed for verification: texlive-xetex, texlive-latex-extra, texlive-lang-polish, texlive-bibtex-extra, biber, latexmk, texlive-fonts-extra and texlive-fonts-recommended. Poppler tools support PDF inspection. The unmodified thesis was compiled successfully before writing began.

- `validation.json`: independent recomputation of all four errors for both runs at overall, series and horizon scopes; 723,600 main and 237,072 sensitivity forecast rows; positive finite MASE denominators; all 99 main model/task targets and timestamps aligned to the exact cached loader output.
- `package_validation.json`: all 396 main table values and unrounded minima; 48 context score cells; 40 flag deltas; correlation values/counts; selection IDs/scores; all 44 requested configurations; tuning targets/scales aligned to main data; LaTeX inputs/citations/labels and input hashes.
- `dataset_inventory.csv`, `series_inventory.csv`, `timestamp_gaps.json`: available versus loaded lengths, boundaries, missing/irregular intervals, units caveats and scale evidence.
- `forecast_selections.json`: exact IDs, test-selection rank, origins, history lengths and scores. Weather's damaged unit string is preserved here while the display uses `max. PAR`.
- `correlations_smape.csv` reproduces the original analysis; `correlations_mase.csv` is explicitly additional descriptive analysis and does not overwrite the original.
- Rendered review inspected the dataset/settings/metric/feature/paper tables, both complete sMAPE/MASE comparisons, all six diagnostic forecasts, horizon panels, feature scatter panels, context plot, flag tables, boundaries, full raw-score tables and context-score appendix. Raw-score tables were transposed to avoid overflow; Weather gained a continuation detail panel; ECL scatter sample sizes were corrected to valid pairs.

## Limitations and unrelated existing issues

There are no benchmark-writing integration or build blockers. The text explicitly documents unknown archive calendar/variable mappings, absent checkpoint revision hashes, historical dirty source provenance, requested versus compiled TimesFM settings, unequal histories, custom TabPFN adaptation and single-origin/test-selected analyses. Those limitations cannot be repaired through prose or by inferring undocumented facts.

The broader inherited thesis is not being certified as publication-ready. Its literature chapter retains six existing `\\todo` notes, an `[EXPLANATION NEEDED]` marker, and broad uncited background claims; one pre-existing line remains overfull. The title page still contains template material in the secondary title, and the glossary contains template examples. These are outside the focused handoff. Unsupported pretraining recipes that conflicted with the evaluated checkpoint were removed, and completed-contribution claims were aligned. The code README and historical metadata contain the previously audited overbroad Chronos contamination statement; those statements were not used as scientific evidence and historical run records were preserved.

Local integration is the deliverable. No live Overleaf synchronization, commit, push or publication is claimed.
